# Beauty and Co

Monorepo des applications Beauty and Co.

| Dossier | Application |
| --- | --- |
| [`rdv/`](rdv) | Site vitrine et prise de rendez-vous |
| [`back-office/`](back-office) | Back-office de gestion du salon |
| [`carte-cadeau/`](carte-cadeau) | Site d'achat de cartes cadeaux |
| [`point-de-vente/`](point-de-vente) | Point de vente (accueil, caisse, encaissement) |

Chaque application est un projet Next.js indépendant :

```bash
cd <dossier>
npm install
npm run dev
```
